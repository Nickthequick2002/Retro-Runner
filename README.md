# 🎮 Retro Runner

Retro Runner is a simple 2D game developed using **Unity** as part of a **Game Development course**. The project demonstrates basic gameplay mechanics such as player movement, interaction, and level progression, and is intended purely for **educational purposes**.

## ▶️ How to Play (For Users)

You **do not need Unity** or any additional software to play the game.

1. Open the **Executable** folder in this repository  
2. Download all files inside the folder (or download the entire repository as a ZIP file)  
3. Locate the file **Retro Runner.exe**  
4. Double-click the `.exe` file to launch the game  

⚠️ If Windows displays a security warning, click **More info** and then **Run anyway**. This happens because the executable is not digitally signed.

## 📂 Repository Structure

- **Assets/** – Game assets and scripts  
- **Executable/** – Playable Windows build of the game  
- **Packages/** – Unity package configuration  
- **ProjectSettings/** – Unity project configuration files  

## 🛠 Requirements

- Windows operating system  
- No additional software required
